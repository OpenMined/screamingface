😱Development Plan

Summary: Over the next 4 weeks, a small team will rebuild a prototype website, microservices, and protocol into a reliable beta network capable of withstanding Hacker News level scale and security scrutiny. We will then extend it with additional functionality (released every 1-2 weeks) for the following 11 weeks.

Week 1 (“Accessible SOTA”): Static website, 8 local microservices, 3-view taskbar app (local eval studio, token usage/limit tracker, and cache UI) packaged as a python based electron taskbar app for OSX and Linux. SOTA on the multiple choice section of HLE by ensembling gemini-cli, claude code, codex, and ollama. Launch private beta by EOW. Used by OM team.

Goal: ship “something” (basic desktop app prototype and v1 of onboarding website) to internal OpenMined team by EOW

Core User Flow:
	•	Visit homepage and see “sota” claim
	•	Run curl based command to download, install, and configure
	•	All model sources are automatically detected (ollama, claude code, etc.)
	•	codex, claude code, and gemini are automatically configured to use screamingface backend
	•	Start using normal coding CLI but it works better without being noticeably slower.

Week 2 (“Value-for-SOTA”): First two cloud-deployed enclave microservices (cache and cli model runner) and first personal drive asset (model) enables people to share token budget with each other. Local app and static website are updated to show value-for-money tradeoff. The whole OpenMined team now has the ability to share tokens with one another.

Core User Flow:
	•	Visit homepage and see “sota” claim
	•	Run curl based command to download, install, and configure
	•	All model sources are automatically detected (ollama, claude code, etc.)
	•	codex, claude code, and gemini are automatically configured to use screamingface backend
	•	Start using normal coding CLI but it works better without being noticeably slower.
	•	Run out of credits (like we all do), and get prompted (do any of your friends/colleagues have dormant credits they can share?).
	•	Send link to friends for tutorial to setup their tokens
	•	Go to url4.ai and login with account
	•	Create a “model” 
	•	Get handed a URL (the claude code setup url)
	•	Click the url and authenticate
	•	Share the model with a friend, set rate limits for them (e.g. time of day, % of token budget, etc.)
	•	As a feature, can also share “cache” results with friend (rate limited), meaning if they prompt the *exact* same thing as you you’ll get the same result.
	•	Model shows up as option in local endpoint.
	•	Add it to the default ensemble
