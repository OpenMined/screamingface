## 1. Current SERP Reality (March 2026)

### What's Actually Ranking

| Query | Who Ranks | Content Type | AI Overview? |
|-------|-----------|-------------|-------------|
| "best AI coding tool 2026" | Qodo.ai (#1), MIT Tech Review, Faros AI, DEV Community | Listicles dominate. Only Cursor.com ranks as a product page. | Consensus: "no single best tool" |
| "claude code vs gemini cli" | Shipyard.build (#1), Medium, Milvus blog, FreeAcademy, Tembo.io | Blog posts and comparisons. No official pages rank. | Claude = precision, Gemini = context window |
| "LLM router" | RouteLLM/LMSYS (#1), OpenRouter (#2), NVIDIA Blueprint | GitHub repos and product pages | Growing query |
| "copilot alternative" | Panto, DigitalOcean, CodeAnt, OpenAlternative | Listicles | Claude Code, Cline, Windsurf appear as top alternatives |
| "cursor alternative" | Builder.io, Replit, Morph, NxCode, Emergent.sh | Listicles | Cursor's pricing shift (usage-based, June 2026) driving volume |
| "AI coding benchmark" / "SWE-bench leaderboard" | swebench.com, papers, leaderboard sites | Data pages | Opus 4.5 at 80.9% is current leader |

### Key Finding: Product Pages Don't Rank for Discovery Queries
Product homepages do NOT rank for "best AI coding tool" style queries. Content marketing (blogs, comparisons, guides) dominates. To capture discovery traffic, screamingface needs content pages, not just a product page.

## 4. Competitive SEO Landscape (Updated)

### Current SERP Dominance

| Keyword Area | Dominant Players | Content Types |
|---|---|---|
| "best AI coding tool" | Qodo, MIT Tech Review, DEV Community | Listicles, comparison posts |
| "claude code" / "gemini CLI" | Anthropic, Google, Shipyard, Medium | Docs, comparisons, tutorials |
| "AI model comparison" | Artificial Analysis, LMSYS, swebench.com | Leaderboards, data pages |
| "LLM router" | RouteLLM (LMSYS), OpenRouter, NVIDIA | GitHub repos, product pages |
| "cursor alternative" | Builder.io, Replit, listicle publishers | Comparison posts |
| "AI ensemble" | Academic papers, traditional ML blogs | Papers, textbooks — NOT LLM content |

### Gaps (Where Screamingface Can Rank)

1. **"AI model ensemble for coding"** — Returns traditional ML ensemble content (bagging, boosting). NOBODY has written about LLM ensembles for coding. Own the definition.
2. **"Combine Claude and Gemini CLI"** — Fragmented Reddit threads, one or two blog posts. No authoritative guide.
3. **"LLM routing CLI tool"** — RouteLLM ranks but is academic. No consumer-friendly CLI product owns this.
4. **"AI coding benchmark comparison" (kept current)** — Most pages go stale fast. Live auto-updating page = differentiated.
5. **"Warp vs [other CLI tools]"** — Warp is new as a multi-agent terminal. Comparison content barely exists.
6. **"Terminal-Bench results"** — New benchmark with almost no content ecosystem around it yet.
7. **"AI scaffolding quality benchmark"** — Novel concept proven by SWE-bench data. No one has written about it.
8. **"Claude Code vs Gemini CLI"** — Exists but thin. Beatable with comprehensive, regularly updated content.

### OpenMined/Screamingface Current SEO Footprint
**Zero.** A search for "OpenMined screamingface AI ensemble" returns no relevant results. OpenMined ranks for privacy-preserving AI and data governance, not coding tools.

## 6. Three-Month SEO Playbook (Updated)

### Foundational Advantages
- **Unique brand name** — zero keyword competition
- **Verifiable benchmark claims** — linkable, shareable, trust-building
- **Open source** — GitHub ranks well, gets linked organically
- **CLI-first** — curl install is meme-able and shareable
- **"Ensemble" is unclaimed** — can define the term in the LLM coding context
- **Scaffolding narrative** — SWE-bench data proves orchestration matters as much as model choice

### Month 1: Foundation + Category Definition

**Technical:**
- Fast static site, Lighthouse 95+
- Meta tags, OG tags, structured data (SoftwareApplication schema)
- Canonical URLs, sitemap, robots.txt
- Google Search Console + Bing Webmaster Tools
- Comprehensive GitHub README linking to website

**Content:**
- `/how-it-works` page — **define "AI ensemble" for coding before anyone else**
