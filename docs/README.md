# docs/ — AI-agentic decision records

This directory is the committed home for decisions produced by/with AI agents:

- `docs/plans/` — approved implementation plans
- `docs/specs/` — designs and specifications

Scope will be extended (ADR-style records, process docs). Local scratch drafts
that shouldn't be committed go to `.docs/` (gitignored).

The previous `docs/` tree (architecture, setup, glossary, superpowers plans)
was removed in the July 2026 re-foundation — it described the deprecated
desktop app and plugin server. It remains readable at the git tag
`legacy-monorepo-2026-07-08`.
