ScreamingFace — Request Lifecycle

One coding-CLI prompt through the stack — intercept → proxy → ensemble → providers → back

Interception (mutex)

  • • claude-intercept / claude-env-intercept / mitmproxy-intercept
  • • at most one active — registry enforces the conflict
  • • redirects the CLI's outbound call to the local proxy

Backend ownership

  • • direct-API and gateway backends both serve /claude etc.
  • • mutually exclusive per url4 /path — pick one
  • • gateway path: LiteLLM + credential_blobs on :9105

Persistence & UI

  • • eval-runs stores every run (X-SF-Run-Id)
  • • Desktop RunView / Eval Studio polls /eval_runs
  • • tracing spans cover the whole request tree
