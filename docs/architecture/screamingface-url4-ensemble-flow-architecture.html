ScreamingFace — URL4 Ensemble Flow

GET /ensemble · parse → resolve context → fan-out → reduce

Fan-out semantics

  • • each call is tagged [name:weight:]
  • • calls run in parallel, weighted
  • • direct API or AIGateway :9105 per backend
  • • non-ensemble shapes fall back to base interpreter

Context resolution

  • • "text" — plain string
  • • *source — named source expansion
  • • /path — in-process ASGI fetch (/data KV)
  • • https://… — HTTP GET

Reduce & scoring

  • • reducer model merges N answers into one
  • • X-SF-Run-Id header correlates the whole tree
  • • eval-runs persists per-question accuracy
