## Signatures & shapes — as built

### `_serve.py`
```python
class ConfigError(ValueError): ...           # raised before bind (fail-fast) -> CLI exit 2

EndpointHandler = Callable[[Request], Awaitable[str]]
AsgiApp = Callable[[Mapping, Callable, Callable], Awaitable[None]]

@dataclass(frozen=True, slots=True)
class ServeConfig:
    host: str = "127.0.0.1"
    port: int = 4404                                   # SDK default
    default_route: str | None = None                   # unset -> first declared command
    eval_path: str = "/v1"
    concurrency: int = 32
    max_inflight: int = 16
    timeout: float = 120.0                             # per-request AND per-command
    commands: Mapping[str, tuple[str, ...]] = field(default_factory=dict)

    def validate(self) -> None:
        # concurrency/max_inflight >= 1; timeout > 0; host non-empty; eval_path startswith "/"
        # and != /healthz; commands NON-EMPTY; each command path startswith "/" with non-empty
        # argv; command paths disjoint from {eval_path, /healthz}; explicit default_route is a
        # declared command.

    @property
    def resolved_default_route(self) -> str: ...       # explicit, else first command

def resolve(overrides: Mapping[str, object], env: Mapping[str, str],
            toml_path: Path | None) -> ServeConfig:
    # flag > env > toml > default, per field. An EMPTY env var counts as UNSET.
    # `commands` is TOML-only — argv templates are operator config, not a flag.

def make_command_handler(argv: Sequence[str], timeout: float) -> EndpointHandler: ...
def build_node(config: ServeConfig) -> Url4Node: ...            # one endpoint per command + /healthz
def build_asgi_app(node: Url4Node, config: ServeConfig) -> AsgiApp: ...
```

There is **no** `DEFAULT_ROUTES`, `make_llm_handler`, `build_client`, `backend_url`,
`backend_token`, or `routes` — and no `httpx` import. `[commands]` is the only backend kind.

**Command handler:** `asyncio.create_subprocess_exec(*argv, stdin=PIPE, stdout=PIPE,
stderr=PIPE)` (never `shell=True`); `{intent}`/`{context}` substituted per token; context piped
to stdin; `await asyncio.wait_for(proc.communicate(...), timeout)`; on timeout kill +
`ResolutionError`; non-zero exit → `ResolutionError` with a stderr tail; stdout/stderr decoded
with `errors="replace"` so non-UTF-8 output cannot escape as a bare 500.

**ASGI wrapper.** The node owns dispatch and the `Url4Error → HTTP` map; the wrapper adds only
what the node does not:
```python
# lifespan  -> startup ack; shutdown -> await node.aclose()   (no shared client to close)
# http      -> inflight guard (503 + Retry-After) -> asyncio.timeout(config.timeout) (504)
#              -> node.asgi()(scope, receive, guard.send)
```
Backpressure: `if state["inflight"] >= max: 503` then `+= 1` with **no await between**
(atomic on the single-threaded loop) / `finally: -= 1`. `_StartGuard` tracks
`http.response.start` so a timeout cannot double-send after the node began responding.

### `cli.py`
```python
def main(argv: Sequence[str] | None = None) -> int:
    # argparse: subcommands `serve`, `eval`; top-level --version.
    # eval : StaticIOLayer(); evaluate_sync(expr, io); print result; 0 / 1 (Url4Error) / 2.
    # serve: lazy `from url4 import _serve` -> resolve -> validate (ConfigError -> stderr + 2)
    #        -> _warn_exposure -> build_node -> build_asgi_app -> _serve_forever.

_LOOPBACK = frozenset({"127.0.0.1", "::1", "localhost"})   # "" is NOT loopback — it binds all
```
`main` is the console-script entry point; wrapped as `sys.exit(main())`.

## Test doubles

- **subprocess:** real `tr` / `cat` / `python3 -c` commands (hermetic, fast) for command routes.
- **ASGI:** the node's raw-ASGI app driven directly with hand-built scope/receive/send — no
  Starlette `TestClient` (Starlette is not a dependency), no httpx `MockTransport` (no HTTP
  client in the serve layer).
- **uvicorn:** monkeypatch the `cli._serve_forever` seam in serve tests — never bind in a unit
  test. **AIDEV-NOTE:** `test_cli.py::test_serve_forever_without_uvicorn_prints_hint` asserts
  the *missing*-uvicorn branch by calling the real seam, so it only passes when the `[server]`
  extra is absent from the dev venv; with uvicorn installed it calls the real `uvicorn.run()`
  and binds 4404. CI is green because CI has no extra. Follow-up ticket — it is a prior test
  and append-only (rule 5) forbids editing it here.
