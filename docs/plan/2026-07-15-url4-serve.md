# Plan — `url4 serve` (OME-466)

Implements `docs/spec/2026-07-15-url4-serve-spec.md`. Stack: url4 (`sdlc-python`, 95% cov).

> **REVISED per the spec's 2026-07-15 pivot** — built on the existing `url4.Url4Node`
> (endpoint registry + raw-ASGI `asgi()` + `serve()`), NOT a from-scratch Starlette app. No
> `GatewayIOLayer`, no Starlette. Reuses the existing `url4[server]` uvicorn extra.

## Module layout (all under `packages/url4/`)

```
src/url4/cli.py      # main(argv)->int: argparse; `serve`/`eval`; --version; lazy uvicorn seam
src/url4/_serve.py   # ServeConfig + resolve()/validate(); DEFAULT_ROUTES; make_llm_handler,
                     #   make_command_handler; build_node(config, client); build_asgi_app(...)
tests/unit/test_serve_config.py     # precedence + validation
tests/unit/test_serve_backends.py   # LLM handler (fake httpx transport) + command handler (subprocess) + merge
tests/unit/test_serve_app.py        # node wiring + ASGI wrapper: eval, endpoints, /healthz, error map, 503, 504, lifespan close
tests/unit/test_cli.py              # eval (arg/stdin), --version, usage=2, serve wiring (monkeypatched serve seam), missing-uvicorn hint
pyproject.toml       # [project.scripts] url4 = "url4.cli:main"  (reuses existing [server] extra)
```

`url4/__init__.py` unchanged (cli/_serve are entry-point/internal, not SDK surface). `url4/server.py`
is the existing `Url4Node` SDK — do not shadow it with a package.

## Signatures & shapes

### config.py
```python
DEFAULT_ROUTES: dict[str, str] = {
    "/claude": "claude/claude-opus-4-8",
    "/gemini": "gemini/gemini-2.0-flash",
    "/codex":  "codex/gpt-5-codex",
}

@dataclass(frozen=True, slots=True)
class ServeConfig:
    host: str = "127.0.0.1"
    port: int = 4444
    backend_url: str = "http://127.0.0.1:9105"
    backend_token: str | None = None
    processor: str = "/claude"
    concurrency: int = 32
    max_inflight: int = 16
    timeout: float = 120.0
    routes: Mapping[str, str] = field(default_factory=lambda: dict(DEFAULT_ROUTES))
    commands: Mapping[str, tuple[str, ...]] = field(default_factory=dict)

    def validate(self) -> None:  # raises ConfigError (ValueError subclass) — fail-fast
        # concurrency/max_inflight >= 1; timeout > 0; processor in routes;
        # every route/command key startswith "/"; routes & commands keys disjoint.

def resolve(args: argparse.Namespace, env: Mapping[str,str], toml_path: Path|None) -> ServeConfig:
    # precedence flag > env > toml > default, per field. Pure; no I/O beyond reading toml_path.
```
`ConfigError(ValueError)` local to config.py. TOML via `tomllib`.

### io_gateway.py
```python
def merge(intent: str, context: str) -> str: ...  # engine default_process convention

@dataclass(eq=False)
class GatewayIOLayer:                     # satisfies url4.IOLayer Protocol
    backend_url: str
    routes: Mapping[str, str]
    commands: Mapping[str, tuple[str, ...]]
    token: str | None = None
    command_timeout: float = 120.0
    client: httpx.AsyncClient | None = None      # injectable for tests; else lazily created & owned
    async def fetch(self, target: str, *, relative: bool) -> str: ...
    async def aclose(self) -> None: ...
    # private: _plain_get, _llm(path, ctx, intent), _command(path, ctx, intent)
```
- Reuses `url4.subrequest.decode_subrequest`, raises `url4.errors.ResolutionError` on failure
  (wrap httpx errors + non-2xx + subprocess non-zero, mirroring `HttpIOLayer`).
- LLM: `resp.json()["choices"][0]["message"]["content"]`; missing shape → ResolutionError.
- Command: `asyncio.create_subprocess_exec(*argv_substituted, stdin=PIPE, stdout=PIPE,
  stderr=PIPE)`; `await asyncio.wait_for(proc.communicate(context.encode()), command_timeout)`;
  on TimeoutError kill+ResolutionError.

### app.py
```python
def build_app(config: ServeConfig, *, io: IOLayer | None = None) -> Starlette:
    # io defaults to a GatewayIOLayer built from config; lifespan owns aclose if it built it.
    # holds an inflight counter (int) on app.state; handlers:
    #   GET /?q=  -> _evaluate(expr)
    #   POST /    -> body -> _evaluate(expr)
    #   GET /healthz -> "ok"
    # _evaluate: inflight guard (503) -> asyncio.timeout(config.timeout) ->
    #            run(expr, io=io, processor=config.processor, concurrency=config.concurrency)
    #            -> PlainTextResponse; exceptions -> _error_response (JSON + status per §4.1)
```
Backpressure counter: `if state.inflight >= max: 503` then `state.inflight += 1` (no await
between) / `finally: state.inflight -= 1`.

### cli.py
```python
def main(argv: Sequence[str] | None = None) -> int:
    # argparse: subcommands `serve`, `eval`; top-level --version.
    # eval: StaticIOLayer(); asyncio.run(run(expr, io=static)); print; return 0/1/2.
    # serve: resolve config -> validate (ConfigError -> stderr + 2) ->
    #        lazy `from url4.server.app import build_app` (ImportError -> install hint + 2) ->
    #        uvicorn.run(app, host, port, log_level). Warnings for non-loopback host.
```
`main` is the console-script entrypoint; wrap to `sys.exit(main())`.

## Test doubles

- **httpx:** `httpx.MockTransport(handler)` injected via `httpx.AsyncClient(transport=…)` into
  `GatewayIOLayer(client=…)` — asserts method/url/json/headers, returns canned OpenAI JSON.
- **subprocess:** real `python3 -c` commands (hermetic, fast) for command-route tests.
- **ASGI:** Starlette's `TestClient` (httpx-based) for app tests, with `io=` a fake IOLayer or
  a `GatewayIOLayer` over a MockTransport.
- **uvicorn:** monkeypatch `uvicorn.run` in serve tests (never actually bind in unit tests).

## Risks / notes

- Starlette `TestClient` needs the extra installed in the dev env — add `starlette`,`uvicorn`
  to the url4 `[dependency-groups].dev` too (so CI/dev can run server tests) in addition to the
  `[serve]` extra.
- Keep `cli.py` top-level import free of Starlette so `--version`/`eval` work without the extra
  (import isolation test guards this).
