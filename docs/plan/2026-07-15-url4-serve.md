## Signatures & shapes — as built

### `_serve.py`
```python
class ConfigError(ValueError): ...           # raised before bind (fail-fast) -> CLI exit 2

EndpointHandler = Callable[[Request], Awaitable[str]]
HoldingsHandler = Callable[[str | None], Awaitable[str]]   # receives the requested collection
DataCallable    = Callable[[], Awaitable[str]]
AsgiApp = Callable[[Mapping, Callable, Callable], Awaitable[None]]

@dataclass(frozen=True, slots=True)
class ProviderSpec:                                  # one declared READ backend
    value: str | None = None                         # inline text
    file: str | None = None                          # re-read per request, in a thread
    command: tuple[str, ...] | None = None           # argv template; {collection} substituted
    media_type: str | None = None                    # [data] only — drives collection parsing

@dataclass(frozen=True, slots=True)
class ServeConfig:
    host: str = "127.0.0.1"
    port: int = 4404                                   # SDK default
    default_route: str | None = None                   # unset -> first declared command
    eval_path: str = "/v1"
    concurrency: int = 32
    max_inflight: int = 16
    timeout: float = 120.0                             # per-request AND per-command
    commands: Mapping[str, tuple[str, ...]] = field(default_factory=dict)
    # Read-side registries — TOML-only, like commands. Collection key None == default shelf
    # ("default" in TOML, normalized at parse time; TOML has no null key).
    data: Mapping[str, ProviderSpec] = field(default_factory=dict)
    holdings: Mapping[str | None, ProviderSpec] = field(default_factory=dict)
    identities: Mapping[str, Mapping[str | None, ProviderSpec]] = field(default_factory=dict)

    def validate(self) -> None:
        # concurrency/max_inflight >= 1; timeout > 0; host non-empty; eval_path startswith "/"
        # and != /healthz; commands NON-EMPTY; each command path startswith "/" with non-empty
        # argv; command paths disjoint from {eval_path, /healthz}; explicit default_route is a
        # declared command; data paths startswith "/" and disjoint from commands AND
        # {eval_path, /healthz}; identity names match the node's own _IDENTITY_NAME_RE.
        # (Provider-shape errors are raised earlier, at parse time in resolve().)

    @property
    def resolved_default_route(self) -> str: ...       # explicit, else first command

def resolve(overrides: Mapping[str, object], env: Mapping[str, str],
            toml_path: Path | None) -> ServeConfig:
    # flag > env > toml > default, per field. An EMPTY env var counts as UNSET.
    # `commands` is TOML-only — argv templates are operator config, not a flag.

def make_command_handler(argv: Sequence[str], timeout: float) -> EndpointHandler: ...

# Read side — one shared resolver, three registry-shaped adapters over it.
async def _provide(spec: ProviderSpec, timeout: float,
                   collection: str | None = None) -> str: ...   # value | file | command
def make_data_provider(spec: ProviderSpec, timeout: float) -> DataCallable: ...
def make_shelf_handler(spec: ProviderSpec, timeout: float) -> HoldingsHandler: ...
def make_identity_handler(name: str, shelves: Mapping[str | None, ProviderSpec],
                          timeout: float) -> HoldingsHandler: ...  # exact-then-default fallback

def build_node(config: ServeConfig) -> Url4Node: ...   # /healthz + endpoint per command
                                                       # + data()/holdings()/identity() per registry
def build_asgi_app(node: Url4Node, config: ServeConfig) -> AsgiApp: ...
```

There is **no** `DEFAULT_ROUTES`, `make_llm_handler`, `build_client`, `backend_url`,
`backend_token`, or `routes` — and no `httpx` import. `[commands]` is the only backend kind.

**Command handler:** `asyncio.create_subprocess_exec(*argv, stdin=PIPE, stdout=PIPE,
stderr=PIPE)` (never `shell=True`); `{intent}`/`{context}`/`{param:<name>}`/`{params}`
substituted per token via **one regex pass** (`_SUBST_TOKEN_RE`) so substituted values are never
re-scanned; context piped to stdin; `await asyncio.wait_for(proc.communicate(...), timeout)`; on
timeout kill + `ResolutionError`; non-zero exit → `ResolutionError` with a stderr tail;
stdout/stderr decoded with `errors="replace"` so non-UTF-8 output cannot escape as a bare 500.

**Read providers:** `_provide` is the one place a `ProviderSpec` becomes text — `value` returns
inline, `file` does `asyncio.to_thread(Path.read_text)` per request (never blocking the loop;
`OSError` → `ResolutionError`), `command` reuses `_run_command` with empty stdin. The three
`make_*` factories differ only in the signature the node's registry expects, which is why the
resolution logic is shared rather than triplicated. `make_identity_handler` is the one with real
logic: the node holds a single handler per identity, so exact-collection-then-default lives
there, mirroring `Url4Node.fetch_holdings`'s self-holdings lookup.

**ASGI wrapper.** The node owns dispatch and the `Url4Error → HTTP` map; the wrapper adds only
what the node does not:
```python
# lifespan  -> startup ack; shutdown -> await node.aclose()   (no shared client to close)
# http      -> inflight guard (503 + Retry-After) -> asyncio.timeout(config.timeout) (504)
#              -> node.asgi()(scope, receive, guard.send)
```
Backpressure: `if state["inflight"] >= max: 503` then `+= 1` with **no await between**
(atomic on the single-threaded loop) / `finally: -= 1`. `_StartGuard` tracks
`http.response.start` so a timeout cannot double-send after the node began responding.

## Test doubles

- **subprocess:** real `tr` / `cat` / `python3 -c` commands (hermetic, fast) for command routes
  and for read-side `command` providers.
- **read providers:** `value` providers inline in the test; `file` providers against `tmp_path`
  (the live-re-read test writes the file twice between two evaluations, which is the whole
  point of reading per request).
- **new tests go in new modules.** `test_serve_params.py` and `test_serve_reads.py` are separate
  files rather than appends to `test_serve_backends.py`/`test_serve_config.py`. The append-only
  gate (rule 5) diffs at FILE level and cannot tell an append from an edit, so appending turns
  it red and forces `--skip-append-only`, making "were prior tests touched?" unanswerable from
  the gate output. Same precedent as `test_serve_hardening.py` (round 2).
- **ASGI:** the node's raw-ASGI app driven directly with hand-built scope/receive/send — no
  Starlette `TestClient` (Starlette is not a dependency), no httpx `MockTransport` (no HTTP
  client in the serve layer).
- **uvicorn:** monkeypatch the `cli._serve_forever` seam in serve tests — never bind in a unit
  test. **AIDEV-NOTE:** `test_cli.py::test_serve_forever_without_uvicorn_prints_hint` asserts
  the *missing*-uvicorn branch by calling the real seam, so it only passes when the `[server]`
  extra is absent from the dev venv; with uvicorn installed it calls the real `uvicorn.run()`
  and binds 4404. CI is green because CI has no extra. Follow-up ticket — it is a prior test
  and append-only (rule 5) forbids editing it here.
