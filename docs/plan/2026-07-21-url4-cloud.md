# url4-cloud — Implementation Plan

**Epic:** OME-513 · **Spec:** `docs/spec/2026-07-21-url4-cloud.md`
**Supersedes:** `apps/runner` (OME-443 — epic + 20 build tickets Canceled 2026-07-21). OME-446
(url4 SDK execution-observation seam) was kept and **reparented to OME-513**.

**Goal:** Ship `apps/url4-cloud` — a distributed url4 runner. One image, two entrypoints: a
**stateless App** (k8s Deployment/Service/Ingress; REST + WebSocket only) that mints JWT
topic-capability tokens, schedules **k8s Jobs**, and bridges **NATS → WebSocket**; and a
**Runner** k8s Job that executes a url4 expression via `packages/url4` and publishes telemetry
(logs, OTel `gen_ai.*` spans, tokens + USD cost `self`/`subtree`) to NATS. Primary deliverable:
OpenAPI 3.1 + AsyncAPI 3.0 on one JSON-Schema set, rendered beautifully in **Scalar**.

**Tech stack:** Python 3.12 · uv · hatchling (src-layout, four packages) · FastAPI + Pydantic v2 ·
NATS JetStream · kubernetes client · pytest · ruff (`C901`/PLR) + pyright · pre-commit →
`.claude/scripts/run_gates.py`. Reuses aigateway/scoreboard `create_app`/Dockerfile/Helm patterns.

## Build order (dependencies)
Scaffold → protocol + NATS → (auth · REST · JobRunner · Runner) → WebSocket → deploy · docs · e2e.
The mock-runner (in the e2e ticket) lets the App/REST/WS/docs land and be tested before the real
engine seam (OME-446) exists.

## Phase P0 — Foundations

**Pre-commit & git-hook wiring — FIRST, before any package code (§10.1).** This is repo-level
(not app-local): url4-cloud is the first stack to add the **pre-commit** framework, and the repo
runs hooks from a committed `.githooks/` dir via `core.hooksPath`, so pre-commit is chained
through it (a plain `pre-commit install` into `.git/hooks/` is ignored).
- Repo-root `.pre-commit-config.yaml`: `ruff-check` (incl. `C901`/PLR) · `ruff-format` · `pyright`
  · pre-commit-hooks std (trailing-whitespace, end-of-file-fixer, check-yaml/toml,
  check-added-large-files, check-merge-conflict) — the **fast** gate on every commit.
- Heavy suite `uv run .claude/scripts/run_gates.py url4-cloud` (pytest+coverage) → **pre-push** + CI.
- `.githooks/pre-commit`: keep the no-commit-to-main guard, then `pre-commit run`; add
  `.githooks/pre-push` → `run_gates.py` for changed stacks. `git config core.hooksPath .githooks`
  (**currently mis-set to a stale `apps/desktop/.husky/_` — fix it**) + `uv run pre-commit install`.
- **Landing = `repo`** (touches repo-root config + `.githooks`) → recommend its own `repo` ticket
  landing before OME-514's code.

- [x] **OME-514** — scaffold `apps/url4-cloud`: four `src/` packages (`url4_cloud` ·
  `url4_cloud_runner` · `url4_cloud_nats` · `url4_cloud_protocol`); `pyproject` (uv/hatchling, two

## Non-goals / deferred (from OME-443, not v1)
Recursion / internal child sessions; singleton reaper + fencing; external (uncontrolled) nodes;
per-tree container budgets; a persistent trace store beyond JetStream retention; multi-tenant
identity. See spec §1.3.
