# Plugin Dependency Audit

Audit of cross-plugin imports under `apps/server/src/screamingface/plugins` against each plugin's `Plugin.depends` manifest. Generated by `sf plugin-audit deps`.

`Plugin.depends` is a runtime activation contract — only production imports require a declared dependency. Test-only cross-plugin imports (under `tests/`, `test_*.py`, or `conftest.py`) are reported separately as informational.

## Summary

- Plugins audited: **27**
- Plugins with **missing** prod deps (imported by production code, not declared): **12**
- Plugins with test-only imports of undeclared plugins: **6** (informational)
