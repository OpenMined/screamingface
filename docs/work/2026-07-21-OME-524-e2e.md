# OME-524 — docker-compose e2e + headless integration

## Intent
Prove the full url4-cloud flow end-to-end without a cluster (spec §11; docs/protocol.md §8): a
§8-valid MULTI-NODE mock runner publishes logically-correct CloudEvents, and a **headless**
integration test drives `POST /token → open WS → GET /?q= → stream → DELETE → purge` against the
`InMemoryBus` + a fake `JobRunner` (the container stand-in), asserting every streamed frame
validates via `OutboundFrameAdapter` and satisfies §8 (monotonic sequence, `total_usd == Σ parts`,
`subtree.total == self + Σ children`, well-formed span tree, `CostUsage{subtree}` before `Result`).
A `docker-compose.yml` (NATS JetStream + App + Docker mock-runner) is delivered as the **owner-run**
compose artifact; live `docker compose up` needs real Docker/NATS (INFRA rule — not gated).

## Planned changes
- `apps/url4-cloud/src/url4_cloud/testing/{__init__,mock_runner}.py` — the §8 multi-node mock
  publisher: `build_run()` (pure) + `publish_mock_run(bus, …)` (tested) + `main()` (env→NatsBus,
  INFRA-excluded).
- `apps/url4-cloud/src/url4_cloud/app.py` — additive `create_app_from_env()` (INFRA-excluded) so the
  compose App service wires `NatsBus` (+ shutdown close). `create_app` unchanged.
- `apps/url4-cloud/tests/integration/test_e2e_compose_flow.py` — headless full-flow e2e.
- `apps/url4-cloud/tests/integration/test_mock_runner_stream.py` — direct §8 invariants on the raw
  mock stream through `InMemoryBus`.
- `apps/url4-cloud/docker-compose.yml` + `apps/url4-cloud/Dockerfile` — owner-run compose e2e.

## Test plan
- Direct: `publish_mock_run` → `InMemoryBus.subscribe` → 11 frames; each round-trips through
  `OutboundFrameAdapter`; monotonic 1..11; `subtree.total == Σ self`; token roll-up; span parents
  refer to emitted spans; `subtree` precedes `result`; terminal `succeeded`.
- E2E: mint token → attach WS → async `GET` schedules the fake job which publishes the mock stream →
  WS streams the §8 frames (validated + roll-up + ordering asserted) → `DELETE` → stream purged.

## Acceptance
- `run_gates.py url4-cloud` ALL GREEN; the mock stream is §8-valid by construction and the e2e
  proves the App bridges it faithfully; `docker compose up` documented as owner-run.
