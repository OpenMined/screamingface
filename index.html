One command to install.

screamingface detects every model on your machine and configures itself automatically. Nothing is sent to a server during setup. Nothing is downloaded during use. Nothing is the product.

bash
$ curl -fsSL https://screamingface.ai/install | sh
# detecting models...
found claude-code  •  found gemini-cli  •  found ollama
downloaded: 0 bytes  •  CUDA errors: 0  •  regrets: 0
ready to scream.
01

Install

One command. Downloads the CLI. Does not download 810 GB of Llama weights. You're welcome.

02

Auto-detected

Reads your PATH and existing configs. Claude Code, Gemini CLI, Codex, and Ollama are found and wired up automatically. No CUDA. No cuDNN. No PyTorch version matrix. No tears.

03

Just code

Use your normal CLI workflow. We route every prompt through url4 to whichever model scores best on the task. It's like a mosh pit but for tokens.
