screamingface

Open-source model ensemble for your terminal

Routes prompts across the models you already use. Picks the best response. Runs locally.

No accounts. No API keys you don't already have. Open source.

Install:
$ curl -fsSL https://screamingface.ai/install | sh
How it works:
  1. Detects models on your PATH
  2. Routes each prompt to the best model for the task
  3. Ensemble mode runs all of them, picks the best output
  4. Nothing leaves your machine
Why:

No single model wins every benchmark. Ensembles beat individual models on SWE-bench, HumanEval, and MMLU, but deploying one is a pain. This makes it one command.
